# Cat Farm

A cozy desktop idle game where typing helps you grow a small cat colony.

Every keyboard press earns coins. Use them to develop locations, rescue unique cats, build homes, add decorations, and gradually expand your cat community.

> The project is in active early development.

## Current prototype

- Global keyboard press counting for Russian and English layouts
- Coins earned from keyboard activity
- Persistent local save system
- Starter-cat onboarding with a custom name
- Cats walk around the starting location and occasionally rest
- Hover over a cat to see its name
- Foundation for locations, unique cat pools, and future rescue mechanics

## Planned features

- Rescue expeditions and lightweight auto-battler encounters
- Unique cats generated for each player and location
- Buildings, decoration, and cat interactions with objects
- Passive income and economy upgrades
- Multiple locations with their own cat populations
- Customization of cats and locations
- A compact, movable desktop mode

## Privacy

Cat Farm counts keyboard presses only. It does not save, transmit, or display the text you type.

## Run locally

Requirements:

- Python 3.14 or newer
- `pygame-ce`
- `keyboard`

Install dependencies:

```bash
pip install pygame-ce keyboard
```

Run the game:

```bash
python main.py
```

## Project status

This is an experimental prototype. Gameplay balance, visuals, encounters, and desktop-mode behavior will evolve during development.
